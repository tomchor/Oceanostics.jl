Baroclinic adjustment and the energy budgets with a free surface

In this example we spin up a pair of mesoscale fronts in a doubly-periodic channel of a HydrostaticFreeSurfaceModel, let them go baroclinically unstable, and close the volume-integrated potential and kinetic energy budgets. The model has a free surface, which exchanges a little energy with the flow through the pressure; the kinetic energy budget below carries that exchange in its pressure term.

Before starting, make sure you have the required packages installed for this example, which can be done with

using Pkgpkg"add Oceananigans, Oceanostics, CairoMakie, NCDatasets"
using Oceananigansusing Oceananigans.Units

Parameters

A 500 km by 1000 km channel, 1 km deep and uniformly stratified. The two fronts are 100 km wide and carry a cross-front buoyancy gradient M², which we set through the balanced Richardson number Ri = N²f²/M⁴ of the thermal wind inside them:

Lx = 500kilometersLy = 1000kilometersH  = 1kilometerf       = 1e-4            # [s⁻¹] Coriolis frequencyN²      = 1e-5            # [s⁻²] stratificationRi      = 20              # []    balanced Richardson number inside each frontw_front = 100kilometers   # [m]   width of each frontM² = √N² * f / √Ri        # [s⁻²] cross-front buoyancy gradient inside each front
7.071067811865476e-8

Grid

Doubly periodic in the horizontal and bounded in the vertical, with 10 km cells and 20 levels.

Derived quantities

The deformation radius Ld = NH/f sets the scale of the instability: the fastest-growing wavelength is λ ≈ 3.9 Ld and the growth rate σ ≈ 0.31 f/√Ri. The free surface has a scale of its own, the external deformation radius L_ext = √(gH)/f: the energy stored in a geostrophic displacement of scale L is a fraction (L/L_ext)² of the kinetic energy of the depth-mean flow that balances it. For the eddies, whose scale is Ld, that fraction is N²H/g, a tenth of a percent here, so the surface is a small reservoir.

α     = M² / f                 # [s⁻¹]   thermal-wind shear inside a frontLd    = √N² * H / f            # [m]     deformation radiusλ     = 3.9 * Ld               # [m]     fastest-growing wavelengthσ     = 0.31 * f / √Ri         # [s⁻¹]   growth rateΔb    = M² * w_front           # [m s⁻²] buoyancy jump across each frontŪ     = α * H                  # [m s⁻¹] thermal-wind velocity at the surfaceg     = Oceananigans.defaults.gravitational_accelerationL_ext = √(g * H) / f           # [m]     external deformation radius@info "Ld = $(round(Ld/1e3, digits=1)) km, λ = $(round(λ/1e3, digits=1)) km in a $(round(Int, Lx/1e3)) km channel, growth time 1/σ = $(prettytime(1/σ))"@info "Δb = $(round(Δb, sigdigits=3)) m s⁻², Ū = $(round(Ū, digits=2)) m/s, L_ext = $(round(L_ext/1e3, digits=0)) km"

Closure

As a turbulence closure, we use an anisotropic diffusivity of momentum and buoyancy. The large horizontal diffusivity keeps the 10 km cells smooth under the centered advection scheme, and the vertical diffusivity is as small as we can make it while still resolving the flow fluctuations:

νₕ = κₕ = 300     # [m² s⁻¹]ν_z = κ_z = 1e-3  # [m² s⁻¹]closure = (HorizontalScalarDiffusivity(ν = νₕ, κ = κₕ), VerticalScalarDiffusivity(ν = ν_z, κ = κ_z))
(HorizontalScalarDiffusivity{ExplicitTimeDiscretization}(ν=300.0, κ=300.0), VerticalScalarDiffusivity{ExplicitTimeDiscretization}(ν=0.001, κ=0.001))

Model

A HydrostaticFreeSurfaceModel with a SplitExplicitFreeSurface, which steps the barotropic mode in substeps short enough for the 100 m/s external gravity wave, at a Courant number of 0.7, so that the time step can follow the flow. The advection schemes are Centered, which add no dissipation of their own, so every sink in the budgets below is one we write down and compute.

model = HydrostaticFreeSurfaceModel(grid;                                    coriolis = FPlane(; f),                                    buoyancy = BuoyancyTracer(),                                    tracers = :b,                                    free_surface = SplitExplicitFreeSurface(grid; cfl = 0.7),                                    timestepper = :SplitRungeKutta3,                                    momentum_advection = Centered(order=4),                                    tracer_advection = Centered(order=4),                                    closure)

Initial condition

The buoyancy is the stratification plus two ramps of width w_front, one rising at y = -Ly/4 and one falling at y = +Ly/4. Their difference returns to zero at the edges of the domain, so b matches across the periodic boundary:

ramp(y, w) = min(max(0, y/w + 1/2), 1)y₁ = -Ly/4y₂ = +Ly/4double_ramp(y, w) = ramp(y - y₁, w) - ramp(y - y₂, w)
double_ramp (generic function with 1 method)

The velocity starts in thermal-wind balance with those fronts, referenced to the bottom, and a little noise on the buoyancy seeds the instability:

using RandomRandom.seed!(8675309)ϵb = 1e-2 * Δb    # noise amplitude, a percent of the front's buoyancy jumpbᵢ(x, y, z) = N² * z + Δb * double_ramp(y, w_front) + ϵb * randn()ramp_prime(y, w) = (-w/2 < y < w/2) ? 1/w : zero(y)double_ramp_prime(y, w) = ramp_prime(y - y₁, w) - ramp_prime(y - y₂, w)uᵢ(x, y, z) = -(Δb * double_ramp_prime(y, w_front) / f) * (z + H)
uᵢ (generic function with 1 method)

The surface starts in balance as well, which spares the run a barotropic adjustment in its first steps. The velocity is referenced to the bottom, where it vanishes, so the pressure gradient vanishes there too: the slope of the surface cancels the gradient of the hydrostatic anomaly at the bottom, g ∂η/∂y = H ∂b/∂y across each front. That is twice the slope that balances the depth-mean jet alone, since the depth-mean gradient of the anomaly, zero at the surface and largest at the bottom, adds as much again. Oceananigans integrates the anomaly over a full cell at the top rather than the half cell above the top centre, which shifts every column's pressure by half a cell of surface buoyancy, so the surface that balances the discrete model has H + Δz/2 in place of H:

Δz = H / grid.Nzηᵢ(x, y, z) = Δb * (H + Δz/2) / g * (double_ramp(y, w_front) - 1/2)set!(model, u = uᵢ, b = bᵢ, η = ηᵢ)

Simulation

A TimeStepWizard, set up by conjure_time_step_wizard!, adjusts the step every ten iterations to keep the advective Courant number at 0.25, which is about an hour while the initial jets are the fastest flow, and never lets it exceed that hour, well inside the inertial period. The external gravity waves are left to the free surface's substeps:

simulation = Simulation(model, Δt = 1hour, stop_time = 40days)conjure_time_step_wizard!(simulation, cfl = 0.7, max_Δt = 1hour)using Oceanosticsadd_callback!(simulation, ProgressMessengers.TimedMessenger(), IterationInterval(200))

The potential energy budget

Given eₚ = -bz, we multiply the budget equation for b by -z. Pulling z inside each derivative splits terms into a transport and a conversion, and over this domain every transport integrates away, leaving just the two conversions:

\[\frac{d}{dt}\int e_p\, \mathrm{d}V = -\int wb\, \mathrm{d}V + \int \Phi\, \mathrm{d}V ,\]

with $wb$ (PotentialToKineticEnergyConversion) the exchange with the kinetic energy and $\Phi = \kappa\,\partial b/\partial z$ (PotentialEnergyDiffusiveVerticalBuoyancyFlux) the work diffusion does against gravity:

eₚ = PotentialEnergy(model)wb = PotentialToKineticEnergyConversion(model)Φ  = PotentialEnergyDiffusiveVerticalBuoyancyFlux(model)∫eₚ  = ∫dV(eₚ)∫wb  = ∫dV(wb)∫Φ   = ∫dV(Φ)∂ₜ∫eₚ = TimeDerivative(∫eₚ)

The kinetic energy budget

This budget is the other side of the exchange, written with eₖ = ½(u² + v²), the energy of the two prognostic velocities in a hydrostatic model. The pressure enters through KineticEnergyPressureRedistribution, $\texttt{PR} = u_j \partial_j (p' + g\eta)$, the work of the whole pressure: the hydrostatic anomaly $p'$ that the buoyancy sets and the surface pressure $g\eta$ of the free surface. It is contracted with all three velocity components, the diagnosed $w$ included, so the budget reads much as it would on a nonhydrostatic model. Both the pressure redistribution and the advective terms stay, since the top of the domain (the surface) has a nonzero $w$. So

\[\frac{d}{dt}\int e_k\, \mathrm{d}V = -\int \texttt{ADV}\, \mathrm{d}V - \int \texttt{PR}\, \mathrm{d}V + \int wb\, \mathrm{d}V - \int \varepsilon_k\, \mathrm{d}V ,\]

with $\texttt{ADV} = u_i \partial_j (u_j u_i)$ (KineticEnergyAdvection). We can calculate these quantities with:

eₖ  = KineticEnergy(model)εₖ  = KineticEnergyDissipationRate(model)ADV = KineticEnergyEquation.KineticEnergyAdvection(model)PR  = KineticEnergyPressureRedistribution(model)∫eₖ  = ∫dV(eₖ)∫εₖ  = ∫dV(εₖ)∫ADV = ∫dV(ADV)∫PR  = ∫dV(PR)∂ₜ∫eₖ = TimeDerivative(∫eₖ)
TimeDerivative of 1×1×1 Field{Nothing, Nothing, Nothing} reduced over dims = (1, 2, 3) on RectilinearGrid on CPU

For the movie we keep the surface vorticity, buoyancy and displacement and the mixed layer depth, in one file with the volume integrals. Each surface map is averaged over its single vertical level, the top level of cells for $\zeta$ and $b$ and the top face of the grid for $\eta$, which leaves it two-dimensional, with no vertical dimension to share with the others. The mixed layer depth is two-dimensional already. We use the default criterion of MixedLayerDepth, the depth at which the buoyancy has dropped by $10^{-4} g$ below its surface value, which the initial stratification reaches about 120 m down:

u, v, w = model.velocitiesb = model.tracers.bζ = ∂x(v) - ∂y(u)ζₛ = Average(Field(ζ, indices = (:, :, grid.Nz)), dims=3)bₛ = Average(view(b, :, :, grid.Nz), dims=3)ηₛ = Average(model.free_surface.displacement, dims=3)MLD = MixedLayerDepth(grid, model.buoyancy.formulation, (; b))

Every budget record carries both tendencies and every source term at the same time. The first record has no earlier state to difference against and is written as zero, so the budgets start from the second.
